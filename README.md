# P Yashwanth Portfolio

A responsive personal portfolio website for a second-year Computer Science student focused on AI, ML, Python, software development, and problem solving.

## Files

- `index.html` — main page structure
- `styles.css` — all layout, theme, and responsive styling
- `script.js` — mobile menu, scroll effect, reveal animation, and contact form interaction
- `resume/P_Yashwanth_Resume.pdf` — placeholder resume file path to replace later

## Run locally

From the project folder, start a local web server:

```bash
cd portfolio
python -m http.server 8000
```

Then open: http://localhost:8000

## Where to update content

- Resume: replace the file at `resume/P_Yashwanth_Resume.pdf`
- Profile photo: add an image and update the `profile-avatar` section in `index.html` if needed
- Project images: update the `.project-visual` blocks or replace with your own image assets in the project cards
- LinkedIn URL: add your actual URL in the placeholder social button section in `index.html`
- HackerRank URL: add your actual URL in the profile card or footer link
- Email: add your email in the contact form section or contact card
- Certificates: add items in the certificates section in `index.html`

## Deploy

### GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository settings.
3. Go to Pages.
4. Select the main branch and root folder.
5. Save and deploy.

### Vercel

1. Import the repository into Vercel.
2. Set the project root to the repository folder.
3. Deploy with default settings.

## Notes

This portfolio is intentionally clean, recruiter-friendly, and easy to edit. You can update the content directly in the HTML without needing a framework.
